# Demo recordings (not supplied yet)

The Experience section plays two files from this folder:

| File | What it must be |
|---|---|
| `demo-original.mp3` | A real vocal take, untouched (the plug-in's ORIGINAL). |
| `demo-processed.mp3` | The same take processed by GlitchKid, same length and start, loudness-matched to the original. |

Rules: a real recording you have the rights to publish; the processed file rendered by the actual GlitchKid build; no other processing added
afterwards. Optional: a credit line in `site.config.json` → `demo.credit` (e.g. artist, which GlitchKid settings were used).
Until both files are here, the site shows a clearly marked placeholder and never plays anything.
