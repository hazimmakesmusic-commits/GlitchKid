# Artist-inspired presets (50)

25 international and 25 Indian DHH presets, built into the plug-in (`Source/Presets/FactoryPresets.*`, table generated by `tools/gen_artist_presets.py` into `ArtistPresets.inc`).

**What they are.** Original starting points described by what they do to a vocal (tuning, formant, EQ, compression, saturation, echo, Dimension, Doubler, Mutation, Harmony, Stutter). The artist name is a reference label only. They are NOT official, NOT licensed, and NOT recreations of anyone's voice or recording chain. No artist photos, logos or artwork are used; every card has an original generated "sigil".

**Rules every preset follows** (all enforced by `Tests/ArtistPresetTests.cpp`)
- Only existing parameter IDs, in range, each set once; never `tune_key`, `tune_scale`, `gain`, `mix` or `bypass`. Loading keeps YOUR key and scale.
- Close to the input level (within about 2 dB on the test voice) and never clipping (output peak <= 0.95 for a -8 dB peak input). Compressor makeup was calibrated from measurements (`tools/calibrate_artist_presets.py`).
- No two presets share settings (closest pair differs in 10 controls) and every one differs measurably from the untouched sound.
- Tuning-on presets add the Pitch Tune delay (about 31 ms) and report it to the host; Formant and Harmony add theirs only where used.

**Browser (AUTO).** Filters: All 50, International, Indian DHH, Melodic Rap, Hardcore / Lyrical, Trap, Drill, Rage / Distorted, R&B / Pop-Rap, Experimental, Punjabi, Hindi / Urdu. Search by artist or name (punctuation ignored: "krsna" finds KR$NA), sort A-Z / origin / style, favourites (saved with the session), eight cards per page.
Click a card to read it (nothing changes); LOAD SOUND (or double-click) applies it live so you can hear it and compare with DRY / PROCESSED; BACK TO MY SOUND restores what you had before (it keeps your ORIGINAL sound while you try several in a row); MODIFY opens the controls.

**Limits.** There is no separate non-destructive preview: auditioning means loading, with BACK TO MY SOUND as the way out. There is no reverb or key detection in the engine, so none is used. Tests use a synthetic voice; nothing has been auditioned on real vocals or in a DAW.
