Experimental Lab

Next milestone. This page only lists which existing effects the Lab would curate. They already run in the plug-in, with parameters and tests, but the current interface hides them (an older session that has them on gets a warning).

Formant

Bigger/darker or smaller/brighter voice without changing pitch. −12…+12 st. Adds ≈21 ms latency while away from 0.

formant_shift
Harmony voice

One extra voice at a fixed interval (octave, fifth, thirds, fourth; up or down), level −24…0 dB. Adds Pitch-Tune-sized latency while on.

harm_on · harm_interval · harm_level
Mutation

Frequency shifter / ring modulator: metallic, robotic, alien. Amount, Character (down · robot · up), Blend. Zero latency.

mut_on · mut_amount · mut_character · mut_blend
Stutter

Beat-repeat of the last slice, tempo-synced 1/4…1/32, with mix. Real audio only.

stutter_on · stutter_rate · stutter_mix

Also candidates at their extreme ranges: Saturation (to 18 dB), Echo (feedback to 90 %), Dimension, Doubler. Build My Mix currently switches the four Lab effects off: that rule must be revisited before Lab presets ship.
